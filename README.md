# Glimmgarten

Queens-artiges Logikrätsel mit endlos generierten Nächten. Setze in jedes Beet genau ein Glühwürmchen.

Statische PWA ohne Build-Schritt: `index.html`, `sw.js`, `manifest.webmanifest`. Fortschritt liegt im `localStorage`.

Nach Änderungen an Assets `VERSION` in `sw.js` hochzählen, damit installierte Apps aktualisieren.
